# 3d2converter
Python script to convert Atari ST CAD 3D 2.0 3d2 files to STL

This script was coded using Luna and it converts 3d2 files made with Stereo CAD 3D 2.0 on an Atari ST to the STL file format that can be used for 3d printing. So if you ever wanted to 3d print your CAD 3D designs or use your Atari Computer to create 3D designs for printing you can use this script to convert it.
